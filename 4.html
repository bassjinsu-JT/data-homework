픽셀 그림 문제 만들기2인 협동

원래는 친구와 함께 하는 활동이지만, 혼자서도 '내가 그린 그림 → 숫자로 바꾸기 → 숫자만 보고 다시 그리기' 순서로 연습해 볼 수 있어요.

활동 순서

  1. 1번 칸에 원하는 대로 색을 칠해 픽셀 그림을 그립니다.
  2. 그린 그림이 자동으로 0과 1의 숫자로 바뀌어 2번 칸에 나타납니다.
  3. '1번 그림 가리기'를 눌러 내가 그린 그림을 가립니다.
  4. 숫자만 보고 3번 칸에 그림을 다시 그려 완성합니다.
  5. '비교하기'를 눌러 1번 그림과 3번 그림이 같은지 확인합니다.
픽셀 그림 예시 — 참고용이에요. '예시로 채우기' 버튼으로 1번 칸에 바로 넣어볼 수도 있어요.
1. 픽셀 그림 그리기
칸을 눌러 원하는 그림을 그려보세요.
2. 숫자로 바꾸기
1번 그림이 자동으로 숫자로 바뀝니다. (1 = 색칠한 칸, 0 = 빈 칸)
3. 다시 그림으로 바꾸기
위의 숫자만 보고, 1번 그림은 보지 않고 그려보세요.
틀린 칸이 있다면 3번 그림에 빨간 테두리로 표시돼요.
혼자 연습할 때도 실제 활동처럼 1번 그림을 가리고 3번을 채워보면 더 재미있어요.
